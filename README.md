🛡️ Shield AI — Defense Intelligence Platform

Shield is a modern airspace monitoring and drone intelligence platform built with React and TypeScript. It provides a futuristic command-center interface for monitoring drone activity, threats, radar stations, and global airspace.

✨ Features
🌎 Global Airspace Map
🚁 Live Drone Detection
📡 Radar Station Monitoring
🚨 Threat & Alert Management
📊 Threat Analytics
🤖 AI Intelligence Dashboard
🛰️ Protected & Restricted Zones
📋 Drone Database
📑 Reports Dashboard
📱 Responsive Design
🌙 Dark Military-Style UI
🛠️ Tech Stack
React
TypeScript
Vite
Tailwind CSS
Framer Motion
Recharts
React Router
Lucide React
🚀 Run Locally
npm install
npm run dev

Open:

http://localhost:5173
📦 Build
npm run build
